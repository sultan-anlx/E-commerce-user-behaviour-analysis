## E-commerce Customer Behaviour Analysis
PROJECT OVERVIEW

This project analyses customer behaviour on an e-commerce website to understand why users do or do not convert into paying customers.

## TOOLS AND SKILLS
- Power Query Editor: Cleaning and preparation of the data.
- Microsoft Excel:  PivotTables and charts to analyse customer behaviour.
- PostgreSQL / SQL: Data Validation and customer behaviour analysis.
- Microsoft Power BI: Created an interactive dashboard to present key insights.

## GOAL
The goal is to identify behavioural patterns and provide data-driven insights that can support better marketing, customer experience, and conversion strategies.

## OBJECTIVES
- Analyse customer behaviour and purchasing patterns.
- Measure the relationship between engagement and conversion.
- Compare conversion across demographic groups and user types.
- Evaluate the influence of advertisements, discounts, and cart activity.
- Create dashboards and reports that communicate business insights clearly.
